## The fortune

> The bug you cannot reproduce is the one you already shipped.

60 characters. One original line of fortune-cookie wisdom for a software developer.

## How it works

`main.py` prints the line to stdout and writes exactly that line (no trailing newline, no padding) to `/output/entry.txt`. Deterministic — the same bytes on every run.
